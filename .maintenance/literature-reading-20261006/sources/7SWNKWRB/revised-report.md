# 一、基本信息

**文章题目**：Importation of taxadiene synthase into chloroplast improves taxadiene production in tobacco（将紫杉二烯合酶导入叶绿体可提高烟草中的紫杉二烯产量）

**文章 DOI 号**：10.1007/s00425-021-03626-z

**期刊名称**：Planta，2021，253：107。

**通讯作者及工作单位**：

- **Ling Chang**：湖北大学生命科学学院生物催化与酶工程国家重点实验室 (State Key Laboratory of Biocatalysis and Enzyme Engineering, School of Life Sciences, Hubei University)。

# 二、研究背景

紫杉二烯 (taxadiene) 是紫杉醇通路的早期专一性中间体，由紫杉二烯合酶 (taxadiene synthase, TS) 利用香叶基香叶基焦磷酸 (geranylgeranyl pyrophosphate, GGPP) 生成。植物的甲羟戊酸 (mevalonic acid, MVA) 途径与甲基赤藓糖醇磷酸 (methylerythritol phosphate, MEP) 途径分处细胞质与质体，为异戊二烯前体供应提供不同背景。酶与底物能否在同一细胞区室相遇，是异源生产的重要约束。

既有研究已在植物及微生物中生产紫杉二烯，但将 TS 直接编码于叶绿体基因组，是否优于核编码后再导入叶绿体，仍缺少同一烟草背景下的比较。作者围绕这一问题，对照叶绿体直接表达、细胞质表达及核编码后叶绿体靶向表达三种策略，评估其对紫杉二烯积累的影响。

# 三、研究思路

作者先将经烟草叶绿体密码子优化的 TS 编码区导入叶绿体基因组，以分子检测确认转化并检验目标代谢物是否形成。在观察到产量较低后，作者增加细胞质表达的 TS，检验同时利用两种区室前体供应能否改善产量；随后通过杂交获得仅保留核转基因的比较材料。最后，作者将核编码的 TS 与叶绿体转运肽融合，比较“在叶绿体内直接合成酶”与“在细胞质合成后导入叶绿体”的生产表现。这一设计从可行性验证推进至策略比较，但各表达系统并非仅改变单一定位变量，后续机制解释仍需保留这一限制。

# 四、研究方法

- **转基因体系构建**：以烟草 *Nicotiana tabacum* cv. Petit Havana 为宿主，分别进行叶绿体转化和农杆菌介导的核转化，建立三类 TS 表达策略及相应比较材料。
- **Southern 与 Northern 印迹**：分别检验叶绿体基因组整合、野生型基因组残留和 TS 转录本积累。
- **定量逆转录 PCR**：以烟草 β-Actin 为内参比较核转化系中的 TS 转录水平，区分转录差异与产物积累差异。
- **气相色谱–质谱联用 (gas chromatography–mass spectrometry, GC–MS)**：对叶片提取物进行产物鉴定和内标定量，以干重为基准报告紫杉二烯含量。
- **统计比较**：图注报告均值、标准差及相应检验；不同图中的重复定义按各自图注解释，不能将技术重复当成独立植株。

# 五、实验设计及结果分析

### (一) 叶绿体表达系统能否形成具有代谢活性的 TS

#### 实验目的与设计逻辑

直接进行叶绿体转化，意在让 TS 的表达位置与质体前体供应相一致。然而，获得抗性材料并不等于确认外源基因正确整合，更不能直接证明目标产物已经生成。作者因此依次设置基因组、转录和代谢物三层检测，将“转化成功”与“生产成功”分开判断。野生型烟草是基因组图谱和代谢分析的重要参照，对应的转基因材料则用于检验各层证据是否一致。

#### 实验结果与证据解析

Figure 1a 给出了 pHW4 表达盒在叶绿体基因组 *trnfM–trnG* 区域的整合设计，以及 Southern 检测所依据的酶切位点和探针位置。该图的作用是预先界定不同基因组状态应产生何种片段。Figure 1b 中，野生型对应 3491 bp 片段，两个转基因系对应 4107 bp 片段；在检测灵敏度范围内未见转基因材料保留野生型对应信号。作者据此判断材料达到同质化，即叶绿体基因组群体主要由转化型构成。这属于基因组层面的证据，不能单独说明酶的表达量或催化效率。

Figure 1c 进一步显示转基因系中约 2400 nt 的主要 TS 转录本，下方的溴化乙锭染色凝胶用于提供 RNA 上样状态的参照。更大和更小的弱信号，作者解释为可能的通读转录或编码区内替代转录起始；这属于依据转录本大小提出的解释，并非逐一鉴定了各条带的分子身份。正文还转述种子抗性不分离和植株生长情况，但本次附件中未获得相应 Supplementary Figure 原图，不能将正文转述写成已直接检查了补充图像。

Figure 2 将证据链推进到产物层面。野生型提取物色谱为背景参照，转基因材料在 13.47 min 出现与紫杉二烯对应的峰，目标峰的质谱与既有紫杉二烯质谱特征相符。Figure 2a、2b 分别说明背景与转基因材料的峰差异，Figure 2c 提供质谱支持，Figure 2d 则比较材料间的产物积累。这里的鉴定依据是色谱信号与质谱特征的组合；原文未报告在本实验中进行标准品共进样或 NMR 确证，因此不能补写这些验证步骤。

正文报告转质体烟草叶片积累 **3.6–7.0 μg/g 干重的紫杉二烯**，摘要将该体系的积累水平概括为约 5.6 μg/g 干重。Figure 2d 的柱状图使用均值±标准差，图注标明 n = 3，并以单因素方差分析 (one-way ANOVA) 和不同字母表示统计分组；该图注未进一步明确 n 是否对应独立植株，因此不补造重复单位，也不依据柱高给每个转基因系推算新的精确均值。原文未提供精确 P 值，字母分组不能转换为人为设定的 P 值。

这些结果支持叶绿体表达体系能够实现紫杉二烯的新生形成，但并不意味着已经生产了紫杉醇。两者之间仍有多步氧化和酰化等后续转化。转录本存在与产物形成也不能替代蛋白丰度测定：本研究没有以特异性蛋白检测建立 TS 数量与产量的定量关系，因此不能仅凭 Northern 信号便认为翻译过程已达到最优状态。

### (二) 增加细胞质 TS 是否能够改善前体利用

#### 实验目的与设计逻辑

叶绿体直接表达能够生成产物，却只获得较低积累水平。作者进一步检验一个工程假设：若在已有叶绿体 TS 的背景中增加细胞质 TS，是否能额外利用 MVA 途径相关的前体供应，从而提高总产量。作者将不含叶绿体转运肽 (transit peptide, TP) 的 TS 经核转化导入 Nt-pHW4#5，并利用杂交获得仅保留核转基因的材料。这个比较有助于检验所测试的联合策略是否有效，同时也需要区分策略表现与前体通量的直接测量。

#### 实验结果与证据解析

Figure 3a 界定 pHW37 的核表达设计，TS 由双 CaMV 35S 启动子驱动。Figure 3b 显示不同超转化系的 TS 转录水平，使用 NtActin 内参归一化，并将 #1 系设为参照；图注报告 n = 3 生物学重复及标准差，表达比较采用双侧 Student’s t 检验，以星号表示阈值。该结果用于确认核表达材料中存在不同程度的转录积累，但不直接反映蛋白在细胞质中的数量、定位准确性或有效活性。

Figure 3c 比较叶绿体表达、联合表达和仅核表达材料中的产物积累。正文明确指出，联合表达系与叶绿体表达系具有相近的紫杉二烯水平，而仅表达细胞质 TS 的材料约为 **0.15 μg/g 干重**。图注报告 n = 3 生物学独立样本、均值与标准差，并采用单因素方差分析比较分组。这里应保留作者所报告的“未提高”结论，不能从柱高自行写出联合表达系的精确浓度，也不能将未经统计支持的视觉差异解释为额外 TS 已造成负面代谢负担。

<!--FIGURE:Figure 3-->

**这些数据直接支持的是：在所测试的构建体与烟草材料中，增加细胞质 TS 没有提高紫杉二烯积累。** 作者进一步据此提出，叶绿体 MEP 途径可能是相关前体的重要来源。然而，本研究没有使用同位素通量测定、区室特异的前体检测或系统性的途径抑制实验，不能仅凭表达比较直接定量 MEP 与 MVA 的贡献比例。GGPP 的可及性、TS 蛋白水平和区室间运输均可影响最终产物量，需要避免把工程结果升级为完整的代谢流确证。

作者讨论了此前在另一烟草物种中开展的途径抑制研究，用以说明这一解释与既有认识的联系。这些既有数据属于论文引用的外部研究，本报告仅按原文说明其论证作用，未独立查阅相应原始论文。它们不能当作本研究新增的对照，也不能消除当前表达比较中的全部混杂因素。该组实验的主要价值，是为后续选择表达区室提供依据，而非单独证明所有低产问题均由底物供应决定。

### (三) 核编码后导入叶绿体为何表现更好

#### 实验目的与设计逻辑

细胞质表达效果较低，而叶绿体直接表达也未达到较高产量，提示“酶最终位于何处”与“酶在哪里被合成”可能共同影响生产表现。作者因此构建 pHW38，将核编码 TS 与拟南芥 Rubisco 小亚基来源的 TP 融合，使其预期在细胞质合成后进入叶绿体。这个设计既保留质体靶向策略，又改变表达与蛋白成熟背景，可以检验第三种工程路径是否优于前两种，但不能仅凭结果锁定某一种翻译后修饰。

#### 实验结果与证据解析

Figure 4a 显示核表达构建体的 T-DNA 结构及 TP–TS 融合关系。Figure 4b 比较 10 个转化系的 TS 转录水平，作者选取高、中、低表达的 #2、#7、#3 材料进入产物比较。图注说明表达量相对于 #1 归一化，误差线为 n = 3 生物学重复的标准差，星号表示与 #1 的双侧 Student’s t 检验阈值。不同转化系之间存在表达差异，因此“转运肽有效”与“表达量较高”两种因素不能被简单视为相互独立。

Figure 4c 比较这些材料与叶绿体直接表达材料的紫杉二烯积累，采用均值±标准差及单因素方差分析。原文摘要和结果段报告 Nt-pHW38#2 的最高积累水平约为 **87.8 μg/g 干重**。应将这个明确报道的数值保留为“原文报告的最高水平”，不根据柱高另行估算均值，也不将它与不同批次、不同汇总口径的基线数值直接相除，生成看似精确的提升倍数。图中统计分组支持高表达 TP–TS 系与所比较材料之间存在产量差异，但未给出可供报告的精确 P 值。

<!--FIGURE:Figure 4-->

作者指出不同核转化系的产物积累与 TS 转录水平相关，并在讨论中提出，核编码后导入叶绿体的过程可能更有利于适当折叠或蛋白成熟。**表达策略差异对生产表现的影响得到实验支持，具体分子原因仍未被直接确证。** 当前研究未通过荧光共定位、叶绿体分离后的特异性蛋白定量、修饰位点分析或纯化蛋白活性比较，分别检验定位、蛋白数量、折叠状态及修饰差异；因而不能写成已经证明某一翻译后修饰提高了 TS 活性。

### (四) 工程结论与机制解释的边界

三种策略的比较具有实际决策价值：在本文测试条件下，核编码并附加叶绿体靶向序列的材料取得更高的紫杉二烯积累。不过，叶绿体转化使用经过密码子优化的 cTS，而核表达构建体在启动子、表达环境和 TP 融合等方面有所不同。转基因插入位点、拷贝数及表达调控也可能影响最终表现。因此，这不是仅改变定位而其他条件完全一致的单变量实验，不能将全部产量差异归因于转运过程本身。

正文讨论提到，SDS-PAGE 未能直接显示叶绿体表达 cTS 的蛋白信号，对应的补充图未在本次材料中取得。这个描述可提示蛋白表达、稳定性或检测灵敏度方面的问题，却不能等同特异性定量证明“蛋白不存在”，更不能据此排除前体供应限制。把这些候选原因分开，是本研究进一步验证机制的关键；当前最稳妥的结论仍然是表达策略的比较结果，而不是对低产根因的最终鉴定。

全文正文共有 Figure 1–4，分别承担构建与转录验证、产物鉴定与定量、联合区室策略检验、核编码靶向策略比较的作用；没有正文 Table 或 Scheme。本报告覆盖了各主图全部子图。Table S1 与 Figure S1–S5 只在正文中被引用，本次未取得其原始附件，涉及这些内容的表述均限定为作者正文转述，不代表已经直接检查了补充材料。

# 六、总体结论

本研究建立并比较了烟草中不同的紫杉二烯合酶表达体系，证明叶绿体基因组表达能够支持目标中间体形成，而在该体系中增加细胞质 TS 并未提高积累水平。核编码 TS 结合叶绿体转运肽的材料取得更好的生产表现，为植物底盘中的区室化设计提供了直接的策略比较依据。

**论文的核心贡献是区分了“直接在叶绿体内表达酶”与“核编码后导入叶绿体”两条工程路径，并显示二者不能被视为等效生产策略。** 作者据此形成了联系前体区室、表达背景和蛋白成熟过程的解释框架。研究对象及产物为紫杉二烯这一早期中间体，结论为后续途径重构提供基础，不等于完成紫杉醇的全途径生产。

# 七、论文评价

### 优点与创新

论文将区室化问题转化为可比较的植物表达体系，通过基因组整合、转录本和代谢物检测连接构建与生产表现。联合表达策略及仅核表达的比较材料，使“增加一个表达模块就能提高产量”的设想受到实际检验。其主要价值是工程路线的选择依据；不同构建体并非严格单变量比较，因而机制解释应保持克制。

### 未来研究方向

优先补充匹配表达背景下的 TS 蛋白定量与定位验证，比较叶绿体直接表达和核编码导入材料的蛋白数量及单位蛋白活性，以区分“有效酶量较少”与“相同酶量但成熟状态不同”。若仍需检验前体来源，再通过能够区分区室供应的示踪或代谢检测，避免仅从产物终点推断 MEP 与 MVA 的贡献。

# 八、关键问题及回答

**问题 1：能否据此认定，叶绿体直接表达的低产原因就是 TS 翻译效率不足？**

不能。作者检测到转录本，但缺少 TS 特异性蛋白定量，SDS-PAGE 未显示信号的正文转述也受检测灵敏度影响。低产还可能涉及蛋白稳定性、折叠、有效定位及底物可及性。当前结果支持“转录本存在不足以保证较高生产表现”，尚不能把某一候选原因确定为根因。优先比较相同取样条件下的蛋白数量、区室分布和单位蛋白催化表现，才有机会区分不同解释；该建议属于解读者分析，并非论文已完成的实验。

**问题 2：细胞质与叶绿体联合表达没有提高产量，是否证明 MVA 途径没有贡献？**

没有提高产量并不等于 MVA 贡献为零。该结果针对的是特定构建体、烟草材料和检测条件，既受前体供应影响，也受酶量、运输与代谢分配影响。作者认为数据与 MEP 途径较重要的解释一致，但本研究未直接测量两条途径的通量。适当表述是“增加细胞质 TS 未改善所测试体系的产量”，而不是“MVA 在植物中不参与紫杉二烯合成”。要比较来源贡献，需要增加能够区分前体来源的直接证据。

**问题 3：如何理解 TP–TS 高产结果，而不把蛋白折叠假说写成已经确证的机制？**

应分开三个层次：实验观察是核编码 TP–TS 材料具有较高积累；作者解释是导入叶绿体的过程可能有利于成熟或折叠；解读者判断是表达量与构建体差异仍构成竞争解释。不同转化系的转录–产物相关性不能证明折叠改善，正文也没有直接鉴定修饰位点或伴侣蛋白作用。匹配表达量后比较定位、蛋白稳定性与活性，可以检验导入过程是否仍具有独立优势，并决定应加强表达工程还是研究蛋白成熟机制。
