# 二、研究背景

二萜合酶先建立骨架，细胞色素 P450 氧化酶（cytochrome P450 oxygenases, CYPs）再引入含氧基团。这种模块性使跨物种组合具有扩展化学空间的潜力，但其成功依赖两个不同条件：酶是否接受新的底物，以及接受后是否保持原有区域、立体选择性。底物范围宽不等于氧化位置无差别，保守的氧化位置也不保证所有相关骨架都能反应。

作者选择由 (+)-copalyl diphosphate（(+)-CPP）相关途径生成的三类骨架：pimarane、abietane 与 labdane。研究希望在酵母中组合已知合酶和来自远缘植物的 CYP，获得多种已知或候选未报道产物。其目标是构建化学多样性平台，而不是证明所有产物具有药理活性或已经达到工业生产水平。文中的抗病毒、抗癌等背景来自既有研究，本研究没有相应活性筛选结果。

# 三、研究思路

作者先让十种二萜合酶产生相关骨架，再逐一组合四种 CYP，读取氧化产物。初步筛查后重点选择能由 PsCYP720B4 产生 C-18 酸的组合，再添加其他 CYP 扩展含氧位置。GC-MS 和 LC-MS 适合观察不同类型产物，主要产物进一步纯化并由 NMR 支持结构。

研究并非始终穷尽所有 CYP 子集：第一阶段为十种合酶与四种单 CYP 的 40 个组合，后续根据产物结果选择酸化模块开展双 CYP 和其他组合。作者再把已知结构、NMR 确证、质谱解释与较低置信结构建议整合为反应网络。PsCYP720B4 在双环底物上出现的位点变化最后用对接模型解释，计算承担假说支持，不能替代产物结构证据。

# 四、研究方法

- **酵母异源组合表达**：以 Golden Gate 模块化构建组织二萜合酶、前体供给酶及 CYP/还原酶，检验组合的产物形成能力，未证明各物种天然途径的必要性。
- **GC-MS、HR-GC-MS 与 LC-MS<sup>n</sup>**：覆盖烯烃、醇和酸等产物，比较保留、质量及碎片；不同检测通道不能直接用峰高比较浓度。
- **NMR 与定量分析**：纯化部分主要产物做结构解析，以定量 NMR 信息支持相应产量估计；其余结构保留不同鉴定置信度。
- **机制约束的底物对接**：基于 AlphaFold 模型与近攻击构象标准比较底物可及位置，解释选择性变化；没有实验蛋白复合物结构或动力学验证。

# 五、实验设计及结果分析

### （一）组合规模与产物统计必须和鉴定层级一起理解

Figure 1A 由通用前体 GGPP 出发，区分双功能合酶直接使用 GGPP 与单功能 I 类合酶借助 (+)-CPS 使用 (+)-CPP 两类路线。骨架周围的颜色和星号表示既有 CYP 氧化位点信息，其中括号星号涉及 OsCYP76M8 在 syn/ent 底物上的历史功能，不能当作本研究全部相关位点均已完成验证。Figure 1B 把单 CYP 与双 CYP 产物组织为旭日图，外圈对应作者统计的 **217 种二萜产物**，扇区面积表达数量而非产量、酶活或鉴定可靠性。

Table 1 列出实际使用的酶、物种与登录号。NtGGPPS 供给 GGPP，RoCPS 生成相关双磷酸前体，ATR1 是拟南芥 CYP 还原酶；它们不能算作另三种形成不同骨架的二萜合酶。六种单功能合酶与四种双功能合酶组成十种骨架模块，四种 CYP 分别为 RoCYP76AH22、SpCYP71BE52、OsCYP76M8 和 PsCYP720B4。OsCYP76M8 的典型天然底物构型与本研究主骨架不同，正是检验跨底物接受能力的组成部分。

<!--FIGURE:Table 1-->

作者报告 40 个单 CYP 组合中 31 个检测到氧化产物，形成 110 个氧化产物统计；选择七种能形成 C-18 酸的骨架后，21 个双 CYP 组合给出进一步产物，并另做部分两/三 CYP 排列。正文还使用 190、87、10 等汇总数字，但不同阶段可能重复检出同一产物，不能将这些数字简单相加作为最终独立结构总数。选定的 CYP 有广泛接受能力，失败组合仍然存在，不应表述为十种底物均被四种酶全部转化。

**162 种“new-to-Nature”来自作者当时文献与数据库未查得记录的判断，不等同于 162 种均已纯化并完成完整结构确证。** 正文报告 13 个产物用 NMR 解析，其他结构依赖已知信息、碎片库、HRMS 和酶区域选择性推断，并设定可靠性等级；主文还分别出现“36 已描述、18 质谱解释”与后文“38 质谱比对”等分类表述，具体重叠关系需 SI。不能把缺少数据库命中当成新颖性和准确结构的双重证明。

### （二）海松烷型网络展示串联氧化，也保留中间体与顺序的不确定性

Figure 2A 是位点背景，B、C 是 IrKSL6 相关 GC 与 LC 读数，D 总结该分支的结构关系。只表达合酶时检测到 isopimaradiene（27），增加 PsCYP720B4 时出现酸 119；低丰度醛 36 被作者解释为中间体，但以“likely”描述，不能写成所有氧化步骤均由纯化酶依次实测。再加入 OsCYP76M8 后产生 134，结构被指定为 6β,7α-dihydroxy-isopimara-8,15-dienoic acid，涉及两次羟基化与双键位置改变。SpCYP71BE52 的组合得到 2α-羟基酸 131。

<!--FIGURE:Figure 2-->

Figure 2E、F 分别展示 IrTPS2 分支的 GC 和 LC，G 对应 nezukol（37）的后续网络。RoCYP76AH22 相关组合得到 38，PsCYP720B4 相关组合产生 nezukolic-18-acid（120），增加 OsCYP76M8 后得到 147、148，体现进一步羟基化和环氧化产物。两套色谱各自支持表达组合伴随产物变化，反应图整合其化学关系；不能仅凭共同表达确定每一步实际反应顺序或断言宿主背景完全不参与。

图中不同产物使用不同提取离子集合，灰色编号代表未完整画入网络的产物；未画结构不等于不存在。GC 与负离子 LC 的分析窗口不同，某类酸在 GC 中不明显也不是其未产生的证据。同样，图中归一化后的峰高和某条标注“20×”的展示尺度不能直接用于精确转化率或跨组产量比较，定量需另看 Table 2 与原始校准。

### （三）松香烷型产物揭示网络分支，自发反应不能归给 CYP

Figure 3A 给出 abietane 相关预期位点；B 总结 LAS 产生骨架 58 后的酸化及 2α-羟基化路线，C、D 分别提供相应 GC 与 LC 色谱。作者观察到 LAS 有多个骨架产物，加入 PsCYP720B4 后出现酸 125 和未完整表征产物 124，联合 SpCYP71BE52 后出现 152。组合产生新峰支持酶系统的生产能力，但未充分表征的 124 不应借反应图推断为唯一明确结构。

<!--FIGURE:Figure 3-->

E 描绘 RoMiS 分支，F、G 给出对应色谱。RoMiS 产生 miltiradiene（2），作者指出其自发转为 abietatriene（1）；这一过程不能标作 OsCYP76M8 催化。后者与该模块组合产生 7β-醇 11、酮 13 及其他未完全表征峰，PsCYP720B4 将相应骨架导向酸 19、114，联合氧化后出现 210、211 等产物。两个差向异构羟基酸被报告由 NMR 区分，说明多峰不能简单合并为一个相同氧化产物。

原文讨论已知酸及其衍生物的通道、肿瘤等功能，属于文献背景和后续候选价值，并不是本文产物库的活性验证。本研究既没有筛选所有产物，也没有证明新增氧化必然改善水溶性或药理效果。对于因分离不足而未表征的峰，结构等级和功能等级应各自留空或保留暂定状态。

### （四）双环底物改变氧化位置，产物结构纠正最初假设

Figure 4A 标记 labdane 骨架的预期氧化位点，B 展示 OmTPS3 分支的 GC 读数，C 展示结构解析后的关系。OmTPS3 产生 trans-biformene（20），与 OsCYP76M8 组合产生 6β-醇 22 和 7β-醇 23；与 PsCYP720B4 组合得到醇 26、醛 25 和微量酸。最初作者认为醇可能是预期 C-18 氧化停留的中间体，结构解析却支持 **26 为 trans-biformen-3β-ol**，纠正了原先的位置假定。

<!--FIGURE:Figure 4-->

这说明结构证据优先于“已知酶通常氧化哪里”的类比，CYP 广泛接受骨架与保守选择性并非绝对规律。另一个双环底物 cis-abienol 的醇仍可能为 3β-或 18-羟基结构，作者没有给出唯一指定；labda-7,13E-dien-15-ol 则未被所试 CYP 接受。虽然相关骨架共享 A 环，远离位点的 C 环或侧链仍可能影响可接受性。这是产物对比支持的解释方向，不是已经量化证明某一远端原子控制结合的机制。

### （五）产量仅对选定产物定量，对接提供可检验的选择性模型

Table 2 列出产物、表达组合、菌株编号、GC/LC 方法及 n = 3–5 的浓度。23、26、147 分别为 **2.09 ± 0.16、2.68 ± 0.29、2.38 ± 0.43 mg/L**，对应选定产物，不能推广为全部 217 种都达到这一水平。不同化合物需要相应校准，作者称定量与 NMR 信息相关；没有标准的其他峰只能提示相近水平，不能按响应假定精确相同滴度。主文未明确全部误差类型及独立重复来源，本次不自动指定为生物学 SD。

相同酸 119 在只含酸化酶与再含 OsCYP76M8 的组合中，报告浓度分别为 0.46 ± 0.12 和 0.008 ± 0.001 mg/L，这与进一步分流相容，但不是完整质量平衡或唯一限速证明。表内 148、152、210 的酶栏仅列部分名称，不能把其不完整栏位当成真实全表达组合；应结合相应网络与 SI。本研究主文未详细给出全部培养、校准及载体流程，不能据此直接声称已复现这些产量。

# 六、总体结论

**本文在酵母中用已知二萜合酶与 CYP 的组合扩展了相关骨架的含氧化学空间，并以部分高置信结构展示跨底物接受能力和选择性规律。** 广泛接受性与大体保守的区域选择性并存，双环底物的氧化位点改变则显示这一规律有边界。

酵母平台提供的是组合产物形成的充分性证据，以及具有分级鉴定信息的产物资源；它不等同原生植物途径的必要性确证。研究把结构识别、产物网络与选择性解释相联系，为系统调查相关二萜的酶组合提供了方法基础。其主要价值是扩大可研究的化学多样性，而非将所有候选结构直接赋予新颖性、药理功能或工业适用性。

# 七、论文评价

### 优点与创新

研究选择共享前体背景而又具有不同环系的骨架，有利于比较跨底物接受与位点保持；26 的结构解析修正了基于酶历史功能的预期，显示正交化学证据的重要性。局限主要是大规模产物统计包含不同置信层级、后续组合有选择而非完全穷尽，以及 CYP 解释主要来自异源系统与模型，不能把低置信注释用于反过来证明所有酶均保持同一选择性。

### 未来研究方向

优先对关键例外及低置信峰补充结构与明确底物转化证据，判断组合网络中是否存在非酶反应或宿主贡献。其次独立检验对接提出的姿态解释，并按标准化方法比较定量产物谱，区分底物接受、表达差异与实际催化选择性。以上为解读者建议，本文未完成这些验证。

# 八、关键问题及回答

**Q1：162 种 new-to-Nature 是否相当于发现并完整确证 162 个新化合物？**

**A**：不相当。该数值来自作者对文献和数据库记录的判断，而产物身份使用 NMR、既有结构比对和不同程度的质谱推断。无记录和结构可靠性是两个问题，不能相互替代。主文明确只有部分产物完成 NMR 解析，SI 又设置可靠性等级。因此应把 162 记录为作者的候选新颖性统计，并在具体结构使用时同时读取鉴定等级，不能统一标为完整确证。

**Q2：为什么加入两个 CYP 的酵母产生终产物，仍不足以确定天然反应顺序？**

**A**：共同表达说明系统可形成该产物，不能自动显示哪一个酶先作用。两种酶可能接受多个氧化状态，也可能存在宿主背景或自发过程。网络依据表达差异与已知化学关系提出顺序，但严格顺序还需要明确中间体、底物与单步转化证据。异源生产的充分性也不等于原植物中的必要性，跨物种组合尤其应保留两者区别。

**Q3：Figure 5 的几何距离是否证明 PsCYP720B4 在双环底物上必然优先氧化 C-3？**

**A**：没有。图示是筛选后的模型姿态，A 中两个位置都接近活性氧，距离本身不能定量比较势垒或生成比例。可靠的位点判断首先来自 26 的产物结构，模型为其提供可能解释。若将模型作为证实机制，还需独立验证底物取向或相关结构因素；同样不能从一个例外推出该酶对所有双环底物均按 C-3 氧化。
